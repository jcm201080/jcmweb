Cybersecurity Internship – Log Analysis

Development of a practical project as part of professional training, in collaboration with TSS Cybersecurity ( tssciberseguridad.com ).

The objective of the project is to design and prototype an automated large-scale log analysis system capable of detecting suspicious behavior such as unauthorized access attempts, brute-force attacks and anomalous patterns that are difficult to identify manually.

  • Efficient processing of large log files.
  • Use of Regular Expressions (RegEx) to extract IP addresses, timestamps, users and error types.
  • Threat classification based on frequency, origin and severity.
  • Identification of aggressive IPs and high-value target users (admin, root, etc.).
  • Automated generation of summaries for the technical team.

Main technology stack: Python (re, pandas), text analysis, data visualization and Linux-based workflows. Prior research into Log Parsing techniques applied to cybersecurity, using real-world server datasets.

This project strengthens my skills in data analysis, automation and applied cybersecurity, with a practical approach focused on improving early detection of real incidents.
